# ADR 0002: 홈 지도 동행 필터를 명시적 선택으로 적용

- Status: Accepted
- Date: 2026-09-18
- Related issue or PR: #37
- Related code: `src/features/home/hooks/use-home-viewer.ts`, `src/features/home/hooks/use-map-places.ts`, `src/features/home/hooks/use-place-search.ts`, `src/features/home/components/category-rail.tsx`

## Context

홈은 등록된 반려견을 자동으로 모두 선택하고 장소 조회에 `dogIds`를 전달했다. 서버는 이를 반려견 크기 등의 동행 조건으로 변환한다. 개발 API에서 제주 전체 조회는 36곳을 반환했지만, 크기 태그가 없는 장소 데이터에 소형견 조건을 적용하면 0곳을 반환했다. 사용자가 필터를 선택하지 않아도 처음부터 빈 지도가 보일 수 있었다.

## Options

- 자동 선택을 유지하고 빈 목록에서 필터 해제를 제공한다.
- 동행 필터 없이 시작하고 사용자가 반려견을 선택하면 적용한다.

## Decision

두 번째 방식을 채택한다. 홈을 새로 마운트하면 반려견 선택은 빈 배열로 시작하며, 반려견 목록을 불러와도 자동 선택하지 않는다. 목록 갱신 시에는 사용자가 선택한 유효한 ID만 유지한다.

사용자가 동행 설정에서 반려견을 선택하고 저장하면 지도와 검색 요청에 `dogIds`를 전달한다. 선택을 모두 해제하면 `dogIds`를 생략한다. 미선택 상태는 기존의 “동행 조건 없음” 문구로 표시한다. 선택은 화면 메모리에만 유지하며 영구 저장하지 않는다.

## Consequences

- 최초 조회는 현재 지도 범위 내 장소를 동행 조건 없이 보여준다. 기존 지도 범위, 카테고리, 검색어, 페이지 크기 제한은 그대로 적용된다.
- 전체 장소 노출은 특정 반려견의 출입 가능 여부를 보장하지 않는다. 동행 가능 장소를 좁히려면 직접 반려견을 선택해야 한다.
- 태그가 없는 서버 데이터는 선택 후에도 빈 결과를 만들 수 있다. 조건을 자동으로 완화하지 않고 기존 안내와 필터 해제 버튼을 유지한다.
