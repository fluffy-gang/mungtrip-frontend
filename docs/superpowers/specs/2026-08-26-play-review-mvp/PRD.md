# 멍멍로드 Play 심사 최소 버전 PRD

## 문제

완성 앱 개발과 Google Play 신규 앱 검토를 순차적으로 진행하면 출시 일정에 심사 대기 시간이 추가된다. 신규 개인 개발자 계정은 프로덕션 접근 신청 전에 12명 이상의 테스터가 14일 연속 참여하는 비공개 테스트를 완료해야 하므로, 현재 서비스 방향을 유지하는 작고 완결된 버전을 먼저 배포할 필요가 있다.

현재 홈은 지도, 장소 정보, 추천 코스, 개인화와 아직 동작하지 않는 탭을 함께 노출한다. 이 상태로 제출하면 스토어 설명과 실제 기능이 불일치하거나 핵심 흐름이 미완성으로 보일 수 있다.

## 사용자

- 제주에서 반려견과 방문할 수 있는 장소를 빠르게 찾으려는 국내 여행자
- 로그인이나 개인화 없이 지도와 이용 조건을 확인하려는 사용자

## 목표

- 로그인이나 권한 요청 없이 제주 반려동물 동반 장소를 지도와 목록으로 조회할 수 있다.
- 카테고리 필터와 키워드 검색으로 장소를 좁힐 수 있다.
- 장소 상세에서 방문 판단에 필요한 이용 조건과 연락 정보를 확인할 수 있다.
- 신규 개인 개발자 계정의 비공개 테스트를 가능한 빨리 시작하고, 실제 사용과 피드백을 증빙해 프로덕션 접근을 신청할 수 있는 상태를 만든다.
- 완성 앱 개발은 기존 개발 흐름에서 계속할 수 있도록 심사용 변경을 별도 브랜치로 격리한다.

## 비목표

- 로그인, 회원가입, 계정 삭제 및 소셜 인증
- 반려견 등록과 사용자별 개인화
- 사용자 제보, 후기, 인증, 평점, 찜
- 추천 코스와 여행 일정 생성
- 현재 위치와 위치 기반 정렬
- 결제, 광고, 푸시 알림 및 분석 SDK
- 여행, 찜, 프로필 등 미완성 탭
- 별도 이용약관 동의 절차
- 심사용 앱에서 검증 정보, 추천 코스 또는 여행 동선 설계가 제공된다고 홍보하는 것

## 사용자 흐름

1. 사용자는 앱을 열고 제주 기본 영역의 지도와 장소 목록을 본다.
2. 지도 마커 또는 목록을 탐색하고 카테고리로 장소를 좁힌다.
3. 필요한 경우 키워드로 장소를 검색한다.
4. 장소를 선택해 상세 정보와 반려동물 동반 조건을 확인한다.
5. 전화번호 또는 홈페이지가 있으면 외부 앱으로 연결한다.
6. 앱 정보에서 데이터 출처와 개인정보처리방침을 확인한다.

## 요구사항

- 첫 화면은 제주 기본 영역의 지도, 카테고리 필터, 장소 목록을 제공한다.
- 검색은 인증 없이 동작하며 검색어를 영구 저장하지 않는다.
- 장소 상세는 응답에 존재하는 다음 정보만 표시한다.
  - 장소명, 카테고리, 주소, 대표 이미지
  - 반려동물 동반 조건과 태그
  - 영업시간, 전화번호, 홈페이지
  - 최근 확인일과 데이터 출처
- 로딩, 빈 결과, 네트워크 오류 및 재시도 상태를 제공한다.
- 모든 노출 버튼은 실제 동작해야 하며 무반응 버튼이나 준비 중 화면을 노출하지 않는다.
- 앱 내부에 한국관광공사 제공 데이터 기반임을 밝히고, 방문 전 사업자 확인을 권고한다.
- 위치, 카메라, 마이크, 연락처 등 핵심 기능에 필요하지 않은 권한을 요청하지 않는다.
- 스토어 등록정보는 “공공데이터 기반 반려견 동반 장소 조회”만 설명하고, 이번 버전에 없는 검증·추천·동선 설계를 언급하지 않는다.

## 콘텐츠 출시 기준

- production API에서 제주 장소 30건 이상을 제공한다.
- 서로 다른 카테고리 3개 이상에서 장소를 조회할 수 있다.
- 모든 노출 장소는 장소명과 주소를 포함한다.
- 지도에 노출하는 장소는 유효한 위도와 경도를 포함한다.
- 모든 노출 장소는 반려동물 동반 조건 또는 관련 태그를 하나 이상 포함한다.
- 릴리즈 대표 장소 10건의 상세 API가 정상 응답하고 핵심 필드를 표시한다.
- 깨진 이미지와 외부 링크는 기본 이미지 또는 열기 실패 안내로 대체되어 핵심 흐름을 막지 않는다.
- 한국관광공사 데이터와 이미지의 이용 범위 및 출처 표시 근거를 제출 전에 확인해 보관한다.

## 비공개 테스트 운영 기준

- 중도 이탈을 고려해 15명 이상을 모집하고, 최소 12명이 14일 동안 연속 opt-in 상태를 유지한다.
- 테스터에게 지도 탐색, 카테고리 필터, 검색, 상세, 전화·홈페이지 연결 시나리오를 제공한다.
- 테스터의 기기/OS, 수행 기능, 발견 이슈, 피드백, 조치와 재검증 결과를 테스트 대장에 기록한다.
- Google Play Testing feedback을 기본 피드백 채널로 사용하고 피드백을 정기적으로 검토한다.
- 프로덕션 접근 신청 전 테스터 참여 방식, 실제 사용, 피드백 요약, 반영 변경과 준비 완료 근거를 작성한다.

## 성공 조건

- 신규 사용자가 로그인이나 런타임 권한 요청 없이 홈부터 장소 상세까지 완료한다.
- API 또는 지도 오류가 앱 종료, 빈 화면, 무한 로딩으로 이어지지 않는다.
- Android 7 및 Android 16 실기기에서 핵심 흐름이 정상 동작한다.
- 최종 AAB에 불필요한 민감 권한이 없다.
- Google Play 내부 테스트와 비공개 테스트에서 설치 및 실행이 가능하다.
- 12명 이상의 테스터가 14일 연속 참여하고 핵심 기능을 실제 사용한 기록이 있다.
- 비공개 테스트에서 발견된 critical/high 결함이 모두 해결되고 수정 빌드가 재검증되었다.
- Google Play 프로덕션 접근 신청에 필요한 테스트·피드백·변경·준비 완료 증빙이 갖춰졌다.

## Release Gate

- 제출 직전 production API의 카테고리·목록·검색·대표 상세 요청, NAVER Maps와 개인정보처리방침 URL을 smoke test해 정상임을 확인한다.
- 운영자 문의 이메일, 개인정보처리방침 URL과 릴리즈 담당자가 지정되어 있다.
- 최종 AAB의 권한, SDK, 네트워크 대상과 서버 로그 정책이 Data safety 및 개인정보처리방침과 일치한다.
- Play Console의 계정 검증, 앱 콘텐츠 선언, 스토어 등록정보와 pre-review 필수 검사를 완료했다.
- 핵심 조회 smoke test 또는 필수 Play Console 설정이 실패하면 비공개 또는 프로덕션 제출을 중단한다.

## 열린 결정

없음. 이슈 번호, 운영자 문의 이메일, 개인정보처리방침 URL과 담당자 이름은 Release Gate에서 채우는 실행 식별값이다.
