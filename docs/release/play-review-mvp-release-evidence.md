# Play 심사 최소 버전 릴리즈 체크리스트 및 증빙 기록

제출 후보 AAB 하나를 기준으로 작성한다. 상태는 `미확인`, `통과`, `실패`, `차단` 중 하나만 사용하고, 직접 확인하지 않은 항목은 `미확인`으로 둔다. 증빙에는 저장소 상대 경로, Play Console 화면명 또는 접근 제한된 사내 기록 위치만 적고 credential, token, 서명키, 원문 요청 헤더를 남기지 않는다.

## 제출 중단 조건

- [ ] production 카테고리·태그·목록·검색·대표 상세 smoke test가 모두 통과했다.
- [ ] 콘텐츠 기준(장소 30건, 카테고리 3개, 대표 상세 10건)과 기능 완결성 기준을 모두 충족했다.
- [ ] NAVER Maps와 지도 실패 시 목록 fallback을 확인했다.
- [ ] 개인정보처리방침 URL이 앱과 Play Console에서 동일하고 공개 접근 가능하다.
- [ ] 최종 AAB의 권한·SDK·네트워크 대상·로그 정책이 Data safety 및 개인정보처리방침과 일치한다.
- [ ] 스토어 설명과 스크린샷이 제출 AAB의 실제 기능과 일치한다.

위 항목 중 하나라도 `실패`, `차단` 또는 `미확인`이면 제출하지 않는다.

## Production API smoke test

API origin은 credential과 query를 제외한 HTTPS origin만 기록한다: `미확인`.

| 대상 | 확인 내용 | 상태 | 응답 시각/HTTP 상태 | 증빙 |
| --- | --- | --- | --- | --- |
| 카테고리 `GET /api/v1/categories` | 무인증 정상 응답, 표시 가능한 카테고리 | 미확인 | 미확인 | 미확인 |
| 태그 `GET /api/v1/tags` | 무인증 정상 응답, 표시 가능한 동반 태그 | 미확인 | 미확인 | 미확인 |
| 목록 `GET /api/v1/places` | 제주 bounds, 좌표·장소명·주소·동반 정보 매핑 | 미확인 | 미확인 | 미확인 |
